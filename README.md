## Overview

Web Tools is a collection of browser-run utilities distributed as HTML files, so you can open them straight from your local machine without installing a separate application. The project is meant for simple access to static web pages and tools that execute entirely on the client side.

Since everything runs in the browser, the package works well for offline scenarios and for cases where you want to keep activity contained locally. It is a practical fit for users who prefer lightweight web utilities that can be saved, opened, and reused from a downloaded copy.

## Installation

1. Download or clone the repository.
2. Open the HTML file in a local browser.
3. Keep the files in a folder if you want to reuse them offline.

Example:

    git clone https://github.com/ben-young2003/web-tools-vcurrent.git
    cd web-tools
    open index.html

If your system does not support `open`, launch the main HTML file by double-clicking it in your file manager.

## Usage

Open the primary HTML file in your browser, then choose the tool or page you need. Because the project is file-based, no server configuration is needed for normal operation.

Typical workflow:

1. Save the HTML files locally.
2. Open them in your browser.
3. Use the available web utility directly on your device.
4. Reopen the same file whenever you need it again, even offline.

If you keep multiple copies, make sure you open the latest version of the HTML file you downloaded.

## Configuration

Most behavior lives inside the HTML files themselves. When a tool exposes editable values, those settings are usually stored in the page markup or in browser-side scripts instead of an external service.

A simple local setup might look like this:

    web-tools/
    ├── index.html
    ├── assets/
    └── tools/

If you customize the files, keep a backup of the original HTML so you can restore it later.

## FAQ

**How do I use it?**  
Download the HTML files and open them in a browser. The tools are built for direct local use.

**Does it need a backend or server?**  
No backend is required for normal use. The project is intended to run in the browser.

**Can I use it offline?**  
Yes. After the files are downloaded, they can be opened without an internet connection.

**Where are settings stored?**  
Any configuration is handled locally in the HTML or browser-side logic, depending on the tool.

**What if a page does not open correctly?**  
Check that you downloaded all related files and that your browser supports the features used by the page. If needed, try a different modern browser.
